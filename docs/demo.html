Remove the preview?

  • The preview goes offline for everyone, and links to it stop working.
  • Anything the site saved while running (form messages, sign-ups, uploads) is deleted with it.
  • The branch and its code in GitLab are not touched.
  • To bring it back, push to the branch again or re-run its pipeline; it is up again in about two minutes.

GitLab records that you stopped it (Operate → Environments).
